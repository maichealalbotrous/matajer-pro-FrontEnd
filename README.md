# Matajer-Pro Frontend

[![React](https://img.shields.io/badge/React-19.2.4-61DAFB?style=for-the-badge&logo=react&logoColor=111827)](https://react.dev/) [![Vite](https://img.shields.io/badge/Vite-8-646CFF?style=for-the-badge&logo=vite&logoColor=white)](https://vite.dev/) [![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4-06B6D4?style=for-the-badge&logo=tailwindcss&logoColor=white)](https://tailwindcss.com/) [![React Router](https://img.shields.io/badge/React_Router-7-CA4245?style=for-the-badge&logo=reactrouter&logoColor=white)](https://reactrouter.com/) [![Matajer-Pro](https://img.shields.io/badge/Matajer--Pro-SaaS-6f42c1?style=for-the-badge)](https://github.com/maichealalbotrous/matajer-pro-backend)

The React frontend for **Matajer-Pro**, a cloud-oriented SaaS system for retail operations, sales, inventory, branches, employees, and financial workflows.

## What this frontend demonstrates

- Role-based application flows for administrators, employees, and platform-level users.
- Product and product-variant management, including sizes, colors, prices, SKU values, quantities, and images.
- Inventory views, low-stock reporting, sales invoices, returns, exchanges, settlements, expenses, discounts, and reports.
- Protected routes and authentication context.
- Reusable React components organized by business area.
- API communication through Axios.
- Responsive UI patterns using Tailwind CSS, shadcn-style components, Radix UI, and Lucide icons.

## Technology stack

- React 19.2.4 and React DOM
- Vite 8
- React Router DOM 7
- Tailwind CSS 4
- Axios
- shadcn / Radix UI patterns
- Lucide React
- ESLint and React Compiler tooling

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```

Review the project environment configuration before connecting the frontend to a backend instance.
